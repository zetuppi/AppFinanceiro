# Dinheiro App

Este é um projeto acadêmico desenvolvido por alunos para gerenciar despesas pessoais.

## Como executar o aplicativo

Certifique-se de ter o Node.js e npm instalados.

Siga estes passos:

```sh
# Instalar as dependências
npm install

# Executar o servidor de desenvolvimento
npm run dev
```

O aplicativo será executado em http://localhost:5173 (ou similar).

## Tecnologias utilizadas

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
